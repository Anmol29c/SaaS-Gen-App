# 🤖 SaaS-Gen-App

An AI-powered SaaS application generator built with 
Gemini API and Tailwind CSS.

## 🚀 Live Demo
👉 [saa-s-gen-app.vercel.app](https://saa-s-gen-app.vercel.app)

## ✨ Features
- AI-powered SaaS idea and content generation
- Google Gemini API integration
- Responsive UI with Tailwind CSS
- Deployed on Vercel

## 🛠️ Tech Stack
- Gemini API (Google AI)
- Tailwind CSS
- JavaScript
- Vercel (Deployment)

## ▶️ How to Run Locally
1. Clone the repository
2. Add your Gemini API key
3. Open index.html in browser
