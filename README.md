## 🎯 What It Does

SaaS Generator App explores how an LLM can help turn a product idea into useful SaaS-oriented content and development starting points.

```text
SaaS Idea
   ↓
Gemini API
   ↓
AI-generated Product Output
   ↓
Developer Starting Point
```

## 🚀 Run Locally

```bash
git clone https://github.com/Anmol29c/SaaS-Gen-App.git
cd SaaS-Gen-App
```

Configure your Gemini API key using the project's expected configuration, then open the application according to the repository setup.

**Never commit API keys to GitHub.**
